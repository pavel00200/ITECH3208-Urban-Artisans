# ITECH3208-Urban-Artisans# Urban Artisans – Handmade Crafts E-Commerce Website

## Project Overview

Urban Artisans is a responsive e-commerce website developed as part of the ITECH3209 Project 2 capstone project.

The website supports artisan and handmade product sales through a clean, modern, and mobile-friendly shopping experience. Customers can browse products, save favourites, manage shopping carts, and place orders through an easy-to-use interface.

# Website Features

## Home Page
- Featured collections
- Product categories
- Artisan introduction
- Mobile-friendly layout

## Shop Page
- Browse all products
- Product card display
- Responsive product grid
- Easy navigation

## Product Details
Each product page includes:

- Product image
- Category
- Description
- Price
- Quantity selector
- Add to Cart
- Add to Wishlist

## Wishlist System
Users can:

- Save favourite products
- View wishlist later
- Remove wishlist products
- Revisit saved products

Wishlist data is stored using browser LocalStorage.

## Shopping Cart
Cart functions include:

- Add products
- Remove products
- Update quantity
- Order summary
- Checkout access

## Login and Registration
Users can:

- Register account
- Login securely
- Access protected pages
- Manage sessions

## Checkout and Orders
Authenticated users can:

- Proceed to checkout
- View order confirmation
- Access order history

## Responsive Design
The website supports:

- Desktop devices
- Tablets
- Mobile devices
- Hamburger navigation
- Mobile responsive layouts

The system follows a frontend and backend connected architecture.

Frontend:

```txt
React + Vite + CSS
```

Backend:

```txt
Node.js + Express API
```

Database:

```txt
PostgreSQL
```

Deployment:

```txt
GitHub → Render → Live Website
```

# Running the Project Locally

## Frontend

Open terminal:

```bash
npm install
npm run dev
```

Frontend runs on:

```txt
http://localhost:5173
```

---

## Backend

Open second terminal:

```bash
cd pg-backend
npm install
npm start
```

Backend runs on:

```txt
http://localhost:4000
```
